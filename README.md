# Mobamemin16.2

AKB48 Mail アプリ版のメールを、Windows PCへ個人用バックアップとして保存・閲覧するための非公式ツールです。

配布物は、次の2つの独立したツールに分かれています。

- **API取得・バックアップツール**：iPhoneの通信情報を取得し、メール一覧・本文・画像をPCへ保存します。
- **閲覧ツール**：保存済みメールをPC内で検索・閲覧し、ローカルのお気に入りを管理します。

両ツールは、同じ `バックアップデータ` フォルダーを共有します。

> [!IMPORTANT]
> 本ツールは、ご自身が正当に閲覧できるAKB48 Mailの個人バックアップ用です。公式ツールではありません。

## 主な機能

### API取得・バックアップツール

- iPhoneから、バックアップに必要なメール一覧・メール詳細・画像の通信情報を取得
- 通信取得用のローカルプロキシをポート `8080` で起動
- 取得した認証情報をWindows DPAPIで保護して保存
- メール一覧、本文、画像を共有の `バックアップデータ` フォルダーへ保存
- 「最新1件」「件数指定」「全件」の3種類から取得範囲を選択
- 本文・画像の保存状況、未処理、エラー、ファイル欠損を画面で確認
- 完了済みデータを再取得せず、中断位置からバックアップを再開
- 「安全に中止」による再開可能な終了
- バックアップ処理中のWindowsスリープを抑止

### 閲覧ツール

- 保存済みメールを既定のWebブラウザーで表示
- キーワード、メンバー、日付、画像の有無で検索・絞り込み
- 保存済み画像をメール本文内またはギャラリーで表示
- 一覧画面と詳細画面からお気に入りを登録・解除
- 「お気に入りのみ」で絞り込み
- 詳細画面の上部と最下部に「一覧へ戻る」を表示
- 検索条件とページを保持したまま一覧へ戻る
- 別の `バックアップデータ` フォルダーを選択し、次回起動時にも使用
- 閲覧サーバーを `127.0.0.1` のみに公開し、閲覧ツール終了時に停止

お気に入りは、選択中のバックアップDBにだけ保存されます。AKB48 Mailサービス側のお気に入り状態は変更しません。

## 動作に必要なもの

- Windows PC
- Python 3.12、3.13、または3.14の64-bit版
- iPhone
- PCとiPhoneを接続できる、信頼できる私設Wi-Fiまたは自分のテザリング
- 初回セットアップ時のインターネット接続
- 閲覧用のWebブラウザー

Pythonは、Microsoft Storeのエイリアスだけではなく、実際に使用できる64-bit版をインストールしてください。

## 配布ZIPの展開

配布ファイル名は `Mobamemin16.2.zip` です。

ZIP内には `Mobamemin16.2` という最上位フォルダーを入れていません。Windowsの「すべて展開」を使うと、展開先として作成される `Mobamemin16.2` フォルダーの直下に各ツールが配置されます。

1. `Mobamemin16.2.zip` を右クリックします。
2. 「すべて展開」を選びます。
3. 展開先の末尾が `Mobamemin16.2` になっていることを確認します。
4. 「展開」を押します。
5. 作成された `Mobamemin16.2` フォルダーを開きます。

次の3フォルダーが直下に見える状態が正常です。

```text
Mobamemin16.2
├─ API取得・バックアップツール
├─ 閲覧ツール
├─ バックアップデータ
└─ はじめにお読みください.txt
```

別の解凍ソフトを使う場合も、`Mobamemin16.2` フォルダーを1つだけ作り、その直下へZIPの中身を展開してください。同名フォルダーを二重にしないでください。

## 初回セットアップ

2つのツールは、それぞれ専用のPython環境を使用します。同じPCで両方を使う場合も、各ツールのセットアップを1回ずつ実行してください。

### API取得・バックアップツール

1. `API取得・バックアップツール` フォルダーを開きます。
2. `1_初回セットアップ.bat` をダブルクリックします。
3. セットアップ完了後、ウィンドウを閉じます。
4. 以後は `2_API取得・バックアップツールを起動.bat` で起動します。

### 閲覧ツール

1. `閲覧ツール` フォルダーを開きます。
2. `1_初回セットアップ.bat` をダブルクリックします。
3. セットアップ完了後、ウィンドウを閉じます。
4. 以後は `2_AKB48メール閲覧ツールを起動.bat` で起動します。

`_runtime_do_not_edit` と `内部ファイル_編集不要` は、セットアップおよびプログラム本体のフォルダーです。名前の変更、移動、編集は行わないでください。

## バックアップ手順

### 1. 通信取得を開始する

1. `2_API取得・バックアップツールを起動.bat` を実行します。
2. 「iPhone通信を取得」タブで「通信取得を開始」を押します。
3. 画面に表示されたPCのIPアドレスを確認します。

### 2. iPhoneのプロキシを設定する

1. PCとiPhoneを同じ信頼できるWi-Fiへ接続します。
2. iPhoneのWi-Fi設定でHTTPプロキシを「手動」にします。
3. サーバーにPCのIPアドレス、ポートに `8080` を入力します。
4. Safariで `http://mitm.it` を開き、iOS用証明書をダウンロードします。
5. 「設定」→「一般」→「VPNとデバイス管理」でプロファイルをインストールします。
6. 「設定」→「一般」→「情報」→「証明書信頼設定」でmitmproxy証明書を信頼します。

通信取得は、信頼できる私設Wi-Fiまたは自分のテザリングで、必要最小限の時間だけ行ってください。

### 3. 必要な通信情報を取得する

AKB48 Mailアプリで、次の操作を行います。

1. 受信箱を開きます。
2. メールを1通開きます。
3. 画像付きメールを1通開きます。

ツール画面で、次の3項目が「今回取得済み」になったことを確認します。

- メール一覧
- メール詳細
- メール画像

### 4. 通信取得を終了する

1. PC側で「通信取得を停止」を押します。
2. iPhoneのWi-Fi設定でHTTPプロキシを必ず「オフ」に戻します。
3. 作業完了後、iPhoneでmitmproxy証明書の信頼を解除し、プロファイルを削除します。

### 5. メールを保存する

1. 「バックアップ」タブを開きます。
2. 最初は「テスト（最新1件）」を選びます。
3. 「バックアップを開始」を押します。
4. 最新1件が正常に保存できたことを確認します。
5. 必要に応じて「件数を指定」または「全件」を選び、再度実行します。

完了後は、本文・画像の未処理、エラー、ファイル欠損がすべて0件になっていることを確認してください。残っている場合はバックアップを再実行します。

処理を途中で止める場合は、ウィンドウを強制終了せず「安全に中止」を使用してください。完了済みデータは記録され、次回は必要な項目だけが処理されます。

## 保存済みメールの閲覧

1. `閲覧ツール` フォルダーの `2_AKB48メール閲覧ツールを起動.bat` を実行します。
2. 使用するバックアップデータを確認します。
3. 「検索・閲覧ページを開く」を押します。
4. ブラウザーで保存済みメールを検索・閲覧します。

通常は、2つのツールと同じ階層にある共有の `バックアップデータ` が自動選択されます。

別のバックアップを閲覧する場合は「別のバックアップデータを選択」を押し、`mail.sqlite3`、`raw`、`images` が入っている `バックアップデータ` フォルダーを選択してください。「標準の共有フォルダーに戻す」で既定の保存先へ戻せます。

## 保存されるデータ

バックアップ結果は、展開後の最上位にある `バックアップデータ` へ保存されます。

```text
バックアップデータ
├─ mail.sqlite3
├─ raw
│  ├─ lists
│  └─ details
└─ images
```

- `mail.sqlite3`：メール、画像の保存状態、閲覧ツールのお気に入りなどを管理するSQLiteデータベース
- `raw/lists`：取得したメール一覧の応答
- `raw/details`：取得したメール詳細HTML
- `images`：保存したメール画像

認証情報は `バックアップデータ` には保存されず、API取得・バックアップツール側でWindows DPAPIを使って保護されます。

`バックアップデータ` の本文・画像・DB自体は、ツール独自の暗号化を行っていません。第三者へ共有しないでください。

## データのコピーと別PCでの閲覧

1. API取得・バックアップツールと閲覧ツールを両方終了します。
2. `バックアップデータ` フォルダー全体をコピーします。
3. 別PCで閲覧ツールをセットアップします。
4. 「別のバックアップデータを選択」でコピー先を指定します。

認証情報はWindowsユーザーにひも付くDPAPIで保護されるため、別PCや別ユーザーへ移行する用途には使えません。別PCへ渡すのは、閲覧に必要な `バックアップデータ` だけです。

## トラブルシューティング

### Pythonが見つからない

Python 3.12、3.13、または3.14の64-bit版をインストールした後、`1_初回セットアップ.bat` を再実行してください。

### 初回セットアップを求められる

各ツールの `1_初回セットアップ.bat` を実行してください。2つのツールは別々のPython環境を使用するため、片方だけのセットアップではもう片方を起動できません。

### 通信取得プロキシを開始できない

- ポート `8080` を使用している別のソフトがないか確認します。
- 初回セットアップが正常終了しているか確認します。
- ツールを終了してから、もう一度起動します。

### 通信情報が「今回取得済み」にならない

- PCとiPhoneが同じWi-Fiに接続されているか確認します。
- iPhoneの手動プロキシに、画面表示どおりのPC IPとポート `8080` を設定します。
- mitmproxy証明書のインストールと信頼設定を確認します。
- AKB48 Mailで受信箱、メール詳細、画像付きメールをそれぞれ開きます。

### バックアップ時に401または403になる

認証情報が期限切れになっている可能性があります。通信情報を取得し直してください。

### 429または5xxエラーになる

時間を置いてからバックアップを再実行してください。

### 閲覧ツールにメールが表示されない

- 正しい `バックアップデータ` フォルダーが選択されているか確認します。
- 選択先に `mail.sqlite3` があるか確認します。
- API取得・バックアップツール側で本文の保存が完了しているか確認します。

### 画像の未処理・エラー・ファイル欠損が残る

API取得・バックアップツールでバックアップを再実行してください。正常に保存済みの本文・画像はスキップされ、必要な項目だけが再処理されます。

## セキュリティ上の注意

- 公共Wi-Fiでは通信取得を行わないでください。
- 通信取得中は、PCのポート `8080` が同じLANから接続可能になります。
- 通信取得後は、iPhoneのプロキシを必ずオフに戻してください。
- 作業完了後は、iPhoneでmitmproxy証明書の信頼解除とプロファイル削除を行ってください。
- `バックアップデータ` には私的な本文と画像が含まれます。安全な場所に保存してください。
- サービス仕様変更、認証期限切れ、証明書ピンニングなどにより取得できなくなる場合があります。
- 本ツールは証明書ピンニングなどのセキュリティ機能を回避しません。

## サードパーティーソフトウェア

通信取得にはmitmproxyを使用しています。配布ZIPには、mitmproxy 12.2.3のプログラム本体を変更せず、依存関係メタデータだけを調整したローカル版 `12.2.3+akb48mail.1` が含まれます。

出所、変更内容、ハッシュおよびmitmproxyのライセンスは、`API取得・バックアップツール/THIRD_PARTY_NOTICES.txt` を確認してください。

この記載はmitmproxyなど第三者ソフトウェアに関するものであり、本ツール全体へ同じライセンスを適用することを意味しません。
